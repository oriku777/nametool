# 中3弱点補強課題作成システム

## 📋 概要

このプロジェクトは、北辰テスト結果に基づいて、中3生徒13名（伏木絢奈さんを除く）の個別弱点補強課題を作成するためのシステムです。

### 🎯 主要な特徴

1. **「全体正答率 > 本人正答率」の問題を最優先** - 取れるはずの問題を確実に取る
2. **教材との具体的マッピング** - 各単元に対応する教材、ページ、問題形式を明記
3. **段階的な学習設計** - 基礎から応用へ、測定可能な合格基準を設定
4. **稲見維真さん対応** - 北辰未受験者は定期テスト・授業内テスト基準で作成

## 🚀 使用方法

### ステップ1：PDF データの分析
1. 北辰テスト結果PDFから以下を抽出：
   - 各生徒の総合点・偏差値
   - 教科別得点・偏差値
   - 設問別の正答/不正答データ
   - 全体の設問別正答率

2. 定期テスト・授業内テストの結果を確認（稲見維真さん用）

### ステップ2：「全体正答率 > 本人正答率」の問題を特定
各生徒について、以下の条件に合う問題を優先度順に並べる：
```
全体正答率 が高い（例：60%以上）
且つ
本人の回答が 不正答 または 部分点

例：
- 大問3-②（作図）：全体正答率72% → 本人0%  [最優先]
- 大問2-④（読解）：全体正答率65% → 本人0%  [第2優先]
```

### ステップ3：教材とのマッピング
各問題に対して、以下の教材から対応する学習内容を選択：

**数学:**
- 作図問題 → EIMEIグループ「作図のテキスト」
- 計算問題 → 「校舎対抗バトル大勉強大会テキスト」
- 公式・知識 → 「高校入試数学『絶対暗記事項』」

**国語:**
- 読解問題 → 北辰対応読解教材
- 古文・漢文 → 対応教材

**英語:**
- 文法問題 → 英文法テキスト
- 読解問題 → 英語長文教材
- リスニング → リスニング教材

### ステップ4：課題の詳細化
各課題について、以下を記入：
- 教材名（正確な名称）
- ページ/問題形式（例：P.12-15、大問3問）
- 取り組み方（具体的なアプローチ）
- 合格基準（達成条件を数値化）

### ステップ5：次回北辰までの目標設定
- 総合点目標：前回比で+15～25点程度
- 教科別偏差値目標：+2～4ポイント
- 重点達成目標：最優先課題の完全習得

## 📊 作成のルール（重要）

### ✅ 優先順位の付け方
1. **最優先：** 全体正答率 ≥ 60% かつ本人が落とした問題
   - 理由：「取れるはずの問題」を確実に取ることが最速の得点向上
   - 例：作図問題（正答率72%）を落としている

2. **第2優先：** 全体正答率 40～60% で本人が落とした問題
   - 理由：やや難度がある程度だが、正答可能な範囲

3. **第3優先：** 本人が得意な分野の強化
   - 理由：既に理解がある分野を伸ばすことで得点力アップ

### ❌ 避けるべきパターン
- 全体正答率 20% 以下の超難問ばかり選ぶ
- 本人が既に正答している問題を課題にする
- 教科全体が得意な場合に基礎から始める（時間浪費）
- 教材を指定せず「この単元を勉強しろ」とだけ言う

## 📝 記入例

### ❌ 悪い例
```
【数学】必達課題
- 二次関数の理解を深める
- 北辰テストの過去問を解く
- 完璧に理解するまでやる
```

### ✅ 良い例
```
【数学】必達課題
- 教材名：高校入試数学「絶対暗記事項」
- 内容：二次関数 y=ax² の特性（頂点、軸、開き具合）
- ページ/問題形式：P.18-22 解説 + P.23-25 確認テスト 15問
- 取り組み方：
  1. 解説を読みながら、グラフの描き方を3種類練習
  2. 確認テストで同じパターンを3回繰り返す
  3. 1週間後に再テストして定着確認
- 合格基準：確認テスト 90% 以上（14問以上正答）
```

## ⚠️ よくある質問（FAQ）

**Q1：「全体正答率」のデータをどこから取得するのか？**
- A：北辰テスト結果PDF内の「設問別正答率」セクションから取得

**Q2：稲見維真さんの場合、定期テストのどのデータを使うのか？**
- A：最新の定期テスト（●月実施）の成績、及び最近の授業内テスト結果

**Q3：1つの課題が完成したら、すぐに生徒に提出できるのか？**
- A：はい。ただし、3つの教科（国語・数学・英語）の全課題を揃えてから、生徒に一括提出することを推奨

**Q4：サンプル（〇〇太郎さん）以上に詳しく書く必要があるのか？**
- A：いいえ。サンプルと同等かやや簡潔でも問題ありません。ただし、課題の詳細度は統一してください

**Q5：教材が見つからない場合はどうするのか？**
- A：「利用可能な教材不足」として teaching_materials_summary.md に記録し、代替教材を探すか、その旨をユーザーに報告

## 🎓 教育的な背景

このシステムの基本原則：

1. **「取れる問題を確実に取る」の優先順位**
   - 難問に時間をかけるより、正答率60%程度の問題を完璧にする方が効率的
   - 多くの生徒が難問に目を向けすぎて、基本的な問題を落としている

2. **個別最適化**
   - 各生徒の弱点は異なる
   - 全員が同じ課題をするのではなく、その生徒にとって「今必要な」課題を提示

3. **測定可能性**
   - 「努力する」ではなく「この問題を解く」という具体的行動を指定
   - 合格基準を明確にして、達成/未達を客観的に判定
